# P32: 差异对比页

> **版本:** v1.0 | **页面ID:** P32 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/diff`（独立页面）或作为 MultiPanel 内 Tab（`P20/P21 MultiPanel → DiffTab`） |
| **目的** | 并排显示两个文件/版本的差异，支持合并视图、分栏视图切换 |
| **前置条件** | 用户已登录，进入软件工程切面 |

  - `DiffToolbar` → Diff 工具栏（LayoutComponent）

    - `ViewModeToggle` → 视图模式切换（FeatureComponent）
    - `StatsSummary` → 变更统计（LayoutComponent）
  - `DiffContent` → Diff 核心内容（FeatureComponent）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **选择文件** | 点击 Selector → 弹出下拉菜单 → 选择文件/Git ref |
| **交换 A/B** | 点击 ⇄ 按钮 → 左右两侧文件互换 |
| **跳转到变更** | 点击 ⬆/⬇ 或按键盘 ↑/↓ 在变更间跳转 |
| **切换视图** | 点击 \|\|/≡ 切换 Split/Unified 视图 |
| **拖拽分割线** | 拖动 GutterDivider 调节左右宽度比 |
| **点击 DiffLine** | 高亮选中该行，同步滚动另一侧对应行 |
| **编辑文件** | 点击"在编辑器打开" → 打开外部编辑器 |
| **复制 Diff** | 点击复制按钮 → 复制标准 diff 格式到剪贴板 |
| **创建补丁** | 点击创建补丁 → 生成 .patch 文件下载 |
