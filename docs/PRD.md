# AIIM 需求文档（PRD）

> 版本：v1.0 | 更新：2026-05-26
> 本文档用自然语言描述业务需求，不涉及技术实现细节。

## 一、账号与认证

### F01 用户注册

**需求描述**：用户通过邮箱和密码创建账号，以便使用平台服务。

**验收标准**：
- [ ] 用户输入有效邮箱和密码（≥8位）后可注册成功
- [ ] 邮箱已注册时返回明确错误提示
- [ ] 注册后自动登录并跳转主页

---

### F02 用户登录

**需求描述**：用户使用邮箱和密码登录，以便访问个人账号和聊天记录。

**验收标准**：
- [ ] 输入正确账号密码后即可登录
- [ ] 密码错误时提示"密码错误"
- [ ] 记住登录状态，下次打开无需重新登录

---

### F03 登出

**需求描述**：用户可以退出登录，以便在公共设备上保护隐私。

**验收标准**：
- [ ] 点击登出后清除登录状态
- [ ] 跳转至登录页面
- [ ] 本地缓存的聊天记录保留

---

## 五、富文本消息

### F20 富文本消息（Markdown 格式）

**需求描述**：用户发送的消息支持 Markdown 富文本格式，可包含标题、列表、表格、代码块、图片、视频等多种元素，让内容更丰富易读。

**验收标准**：
- [ ] 用户可发送 Markdown 格式消息
- [ ] 支持的元素：标题（H1/H2/H3）、列表（有序/无序）、表格、代码块（多语言语法高亮）、引用块、分割线
- [ ] 支持在消息中插入图片（可点击放大）
- [ ] 支持在消息中插入视频（点击播放）
- [ ] 接收方看到的消息保持原格式渲染
- [ ] 代码块自动识别语言并高亮

**Markdown 支持的元素清单**：

| 元素 | 示例 | 说明 |
|------|------|------|
| 标题 | `# H1` `## H2` `### H3` | 三级标题 |
| 列表 | `- 列表项` `1. 有序列表` | 无序/有序 |
| 表格 | `| 列1 | 列2 |` | 支持行列编辑 |
| 代码块 | ` ```python ` | 多语言高亮 |
| 行内代码 | ` `code` ` | 片段高亮 |
| 引用块 | `> 引用内容` | 灰色背景 |
| 分割线 | `---` | 内容分隔 |
| 图片 | `![alt](url)` | 可点击放大 |
| 视频 | `[video](url)` 或嵌入标签 | 点击播放 |
| 链接 | `[文字](url)` | 可点击跳转 |

### F40 个别消息震动/声音提醒

**需求描述**：在手机端，用户可针对特定消息启用震动或声音提醒，以便在收到重要消息时及时感知，而不打扰其他普通消息。

**使用场景**：
- 管理员发布重要通知时，希望成员立刻感知
- 密聊/私密对话，用户希望只有这条消息触发震动
- 关键词监控：包含特定关键词的消息触发震动提醒

**验收标准**：
- [ ] 发送消息时，用户可勾选"震动提醒"或"声音提醒"选项（气泡菜单位置）
- [ ] 接收方：收到带震动标识的消息时，手机执行短震动（约 200ms）
- [ ] 接收方：收到带声音标识的消息时，播放提示音（非全局通知音）
- [ ] 用户可在设置中预设默认行为：
  - 默认关闭 / 默认震动 / 默认声音 / 默认震动+声音
- [ ] 震动和声音可单独启用，也可同时启用
- [ ] 震动时长可在设置中调整（短/中/长三档）
- [ ] 声音可在设置中选择提示音类型（默认/滴答/警报/静音测试预览）
- [ ] 对方可看到你发送的这条消息带有震动/声音标识（一个小图标）

**交互示意**：
```

设置页：
  ┌─ 个别消息提醒 ────────────────┐
  │  默认震动      [关闭 ▾]      │
  │  默认声音      [关闭 ▾]      │
  │  震动时长      [中等   ▾]    │

### F41 持久命令模式

**需求描述**：某些命令开启后会成为持久状态，直到用户主动关闭。该状态下，用户所有后续消息都自动应用该命令的行为，不影响正在进行的 AI 生成/绘图等长任务，也不被长任务中断。

**使用场景**：
- `/queue` 排队模式：开启后所有消息进入队列，AI 生成/绘图不被中断
- `/silent` 静音模式：开启后所有消息静默发送，不触发通知
- `/timer` 延时模式：开启后所有消息延时 N 秒发出
- 多个持久命令可以叠加（如 queue + silent）

**命令分类**：

| 类型 | 例子 | 行为 |
|------|------|------|
| 一次性命令 | `/schedule 14:00 "hi"` `/code-review` | 执行一次后恢复默认 |
| 持久命令（新增） | `/queue` `/silent` `/timer N` | 切换持久状态，保持到主动关闭 |

**验收标准**：
- [ ] 持久命令通过第二次触发同一命令关闭（例：发 `/queue` 开启，再发 `/queue` 关闭）
- [ ] 持久命令状态存储在**服务端**，重启/换设备后仍然保持
- [ ] 多个持久命令可以同时生效（叠加）
- [ ] 开启持久命令时，界面显示当前已激活的命令标签（如 `queue` / `silent`）
- [ ] 发送消息时自动应用所有已激活的持久命令
- [ ] 长任务（AI 生成/绘图）进行中时，普通消息进入队列，不中断长任务
- [ ] 长任务结束后，队列中的消息按顺序继续发送
- [ ] 设置页展示当前所有已激活的持久命令，可一键关闭
- [ ] 持久命令可设置生效范围：全局（所有会话）/ 当前会话

**持久命令列表**：

| 命令 | 功能 | 可配参数 |
|------|------|---------|
| `/queue` | 排队模式，所有消息进入队列 | — |
| `/silent` | 静默模式，消息静默发出，不触发通知 | — |
| `/timer N` | 延时模式，每条消息延时 N 秒发出 | N（秒数） |
| `/priority @user` | 优先模式，指定用户的消息优先发送 | @user |

**交互示意**：
```
# 开启排队
> /queue
✓ queue 模式已开启 [queue]

# 输入框上方显示已激活的持久命令标签
┌─────────────────────────────────────┐
│  [queue] [silent]                   │  ← 持久命令标签
│  [文字输入框...                  ]  │
└─────────────────────────────────────┘

# 设置页
┌─ 持久命令 ────────────────────────┐
│  ✓ queue      [当前会话 ▾] [✕]   │
│  ✓ silent     [全局     ▾] [✕]   │
│  + 添加持久命令                  │
└─────────────────────────────────┘
```

### F42 消息钉住（冻结）

**需求描述**：当聊天中某条消息内容较长（如 AI 生成的大段文字、代码、方案），随着新消息不断到来，这条消息容易被"淹没"，想反复查看需要不断向上翻找。用户可以将该消息"钉住"，钉住后该消息在聊天记录中固定显示，类似 Excel 冻结行——始终可见，后续新消息排在它下方继续流动，滚动聊天记录也不会丢失。用户可围绕这段钉住的消息反复查看、实时讨论，也可以一键将其带入 AI 下一轮对话的上下文。

**验收标准**：
- [ ] 任意消息（文本/代码等长内容）可执行"钉住"操作
- [ ] 钉住后消息在聊天流中固定显示，新消息显示在其下方，滚动时钉住的消息保持可见
- [ ] 钉住的消息下方有清晰的视觉标记（如冻结线/边框），区别于普通消息
- [ ] 可随时取消钉住，取消后恢复正常消息流
- [ ] 钉住状态持久化存储在服务端，重新打开会话/换设备后仍然保持
- [ ] 钉住的消息**不会自动**进入 AI 对话上下文
- [ ] 钉住的消息提供"加入下一轮对话"按钮，点击后该条消息作为 AI 下一轮回答的参照内容
- [ ] 每个会话独立管理自己的钉住消息，互不影响

### F32 语音 / 视频输入模式

**需求描述**：用户在手机端发送语音或视频时，输入框旁边只有一个切换按钮，点击在语音模式和视频模式之间切换，支持多种手势操作。

**验收标准**：
- [ ] 输入框旁边有一个切换按钮（默认显示 🎤 语音图标）
- [ ] 点击按钮：语音模式 ↔ 视频模式 切换
- [ ] 当前模式图标高亮，暗示可用

**语音模式（F32a）**：
- [ ] 长按 🎤 开始录音，录音中显示音波动画和时长
- [ ] 松开手指：录音结束，弹出预览，可发送或取消
- [ ] 录音中向左滑动：取消本次录音，图标变红后松手丢弃
- [ ] 录音中向上滑动：松开后语音转为文字，插入到输入框
- [ ] 录音中向斜方向滑动：继续录音，合并到上一段
- [ ] 发送后对方收到语音消息，点击可在线播放

**视频模式（F32b）**：
- [ ] 长按 🎥 开始录像，录像中显示画面预览和时长
- [ ] 松开手指：录像结束，弹出预览，可发送或取消
- [ ] 录像中向左滑动：取消本次录像，图标变红后松手丢弃
- [ ] 录像中向上滑动：松开后生成视频描述文字，插入到输入框
- [ ] 录像中向斜方向滑动：继续录像，合并到上一段
- [ ] 发送后对方收到视频消息，点击可在线播放
