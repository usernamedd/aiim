# 需求文档 - Android 端

> 项目：AIIM - AI 即时通讯 Android 客户端
> 版本：v1.0
> 状态：进行中

---

## L1 自然语言需求

我们需要一个运行在 Android 手机上的即时通讯应用，支持私聊和群聊。用户可以像使用微信、TailGraham 那样，快速找到联系人或群组，发送文字消息，查看聊天历史。应用需要保证消息的即时送达，断网后能自动重连，已发送的消息显示送达/已读状态。同时，应用需要在后台省电、流畅运行，界面美观符合 Material 3 设计规范。

---

## L2 用户需求

| 角色 | 需求描述 |
|------|---------|
| 访客 | 下载 App 后快速注册/登录，开始使用 |
| 普通用户 | 与好友私聊；在群聊中收发消息；查看未读消息数；搜索聊天记录；修改个人资料 |
| 系统 | 接收推送通知；后台保活（相对宽松的电池优化）；网络切换自动重连 |
| 特殊用户 | 深色模式支持；大字体/无障碍支持 |

## L4 研发需求

### 4.1 项目结构

```
app/src/main/
├── java/com/aiim/android/
│   ├── di/                      # Hilt 依赖注入
│   ├── data/
│   │   ├── local/               # Room 数据库、DataStore
│   │   ├── remote/              # Retrofit API、WebSocket Client
│   │   └── repository/          # Repository 实现
│   ├── domain/
│   │   ├── model/               # 领域模型（User, Chat, Message）
│   │   └── repository/          # Repository 接口
│   ├── ui/
│   │   ├── theme/               # Material 3 主题
│   │   ├── auth/                # 登录/注册
│   │   ├── home/                # 主页面 + Tab 导航
│   │   ├── chat/                # 聊天页
│   │   ├── contact/             # 联系人/好友
│   │   ├── group/               # 群聊管理
│   │   └── profile/             # 个人中心
```

### 4.2 技术实现要求

| 项目 | 要求 |
|------|------|
| 语言 | Kotlin 1.9+ |
| 最低 SDK | Android 7.0（API 24） |
| 目标 SDK | Android 14（API 34） |
| UI 框架 | Jetpack Compose（Material 3） |
| 架构 | MVVM + Clean Architecture |
| 依赖注入 | Hilt |
| 状态管理 | ViewModel + StateFlow |
| 网络 | Retrofit + OkHttp |
| WebSocket | OkHttp WebSocket |
| 本地数据库 | Room（SQLite） |
| 图片加载 | Coil（Compose 原生） |
| 导航 | Navigation Compose |
| 并发 | Kotlin Coroutines + Flow |

### 4.3 WebSocket 消息处理

| 事件 | 处理逻辑 |
|------|---------|
| 收到消息 | 保存本地数据库 → 更新会话列表 → 发送 ACK → 若在前台直接显示，若后台发通知 |
| 收到 ACK | 更新消息状态为"已送达" |
| 收到已读回执 | 更新消息状态为"已读" |
| 心跳 Pong | 记录连接健康状态 |
| 连接断开 | 自动重连（指数退避，最大 30s） |

### 4.4 本地数据缓存策略

| 数据 | 缓存策略 |
|------|---------|
| 用户资料 | 首次登录全量同步，后续增量更新 |
| 会话列表 | 实时更新本地，WebSocket 推送时同步 |
| 消息历史 | 本地存储最近 1000 条，触顶时请求服务器补充 |
| 好友列表 | 首次同步，后续增量更新 |
| 群成员 | 进入群聊时拉取，支持搜索 |

### 4.5 推送通知

| 项目 | 实现 |
|------|------|
| Android 13+ | 使用 Permission.POST_NOTIFICATIONS |
| 推送服务 | Firebase Cloud Messaging（FCM）或 自建推送服务 |
| 点击行为 | 跳转对应会话页面 |
