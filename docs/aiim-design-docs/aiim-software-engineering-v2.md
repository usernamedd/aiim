## 1. 产品定位与场景定义

### 1.1 产品定位

AIIM（AI 墨）是一款 **AI-Native 的多行业智能协作平台**。

核心交互模型：
```
聊天（Chat） + 行业切面（Domain Slice） = 行业专业工具
```

不同行业切面在同一聊天框架上叠加不同的专业功能 UI，共享同一套消息基础设施。

### 1.2 行业切面矩阵

| 行业 | 切面名称 | 核心功能 |
|------|---------|---------|
| 通用 | 基础 IM | 文字/图片/文件/语音 |
| 金融研究 | 投资分析 | 仪表盘/研报解读/持仓预警 |
| **软件工程** | **嵌入式 IDE** | **文件树/代码编辑/调试面板** |
| 医疗 | 诊疗辅助 | 病历面板/药品查询 |
| ... | ... | ... |

### 1.3 软件工程切面定位

面向**开发团队**，将聊天窗口扩展为"聊天即工作台"：
- AI 和程序员在同一 context 下协作
- 代码、文件、调试直接嵌入聊天侧边
- 不离开聊天窗口就能完成开发工作流

### 1.4 目标用户

| 角色 | 核心需求 |
|------|---------|
| 开发工程师 | 代码查看、调试、文件协作 |
| Tech Lead | 代码审查、任务分发、进度追踪 |
| 测试工程师 | 调试日志分析、缺陷记录 |
| 全栈研究员 | 跨端协作 + 文档 + 代码一体化 |

## 2. 多端维度架构

AIIM 的多端覆盖有两个独立维度，**必须同时满足**：

```
维度一：屏幕尺寸（响应式布局）— CSS/Tailwind 统一实现
维度二：操作系统（平台适配）— 各平台独立实现 + 共享业务逻辑
```

### 2.2 维度二：操作系统（平台适配）

#### 2.2.1 移动端：Android vs iOS

| 平台差异点 | Android | iOS |
|-----------|---------|-----|
| **UI 规范** | Material Design 3 | Human Interface Guidelines (HIG) |
| **导航栏位置** | 底部导航 / 侧滑 Drawer | 底部 Tab Bar（官方推荐） |
| **返回手势** | 系统返回键 + 左滑手势 | 左滑返回（全局） |
| **通知推送** | FCM / 厂商通道 | APNs |
| **字体** | Roboto / Noto Sans | SF Pro (系统字体) |
| **状态栏** | 深色/浅色跟随 App 主题 | 常为深色内容衬底 |
| **输入法** | 第三方键盘适配复杂 | Keyboards 适配较简单 |
| **安全区域** | 刘海/水滴需手动处理 | Safe Area 自动处理 |
| **文件访问** | 可访问外部存储 | 沙盒模式，仅 App 目录 |
| **权限弹窗** | 运行时申请，可跳转设置 | 首次申请，解释用途 |

**Android 特有：**
- 物理返回键拦截处理
- 多任务窗口（分屏画中画）
- 通知渠道（Notification Channel）

**iOS 特有：**
- Dark/ Light mode 自动跟随系统
- AirDrop 分享
- 通用链接（Universal Link）深度唤起
- 动态字体大小（Dynamic Type）

#### 2.2.2 桌面端：Windows vs macOS vs Linux

| 平台差异点 | Windows | macOS | Linux (Ubuntu) |
|-----------|---------|-------|----------------|
| **窗口装饰** | 系统标题栏（含控件） | 无标题栏（自绘） | 无标题栏（自绘） |
| **快捷键修饰键** | `Ctrl` | `⌘ Command` | `Ctrl` |
| **菜单栏位置** | 窗口内或应用菜单栏 | 顶部系统菜单栏 | 窗口内或 GTK 菜单 |
| **通知中心** | Windows Action Center | Notification Center | libnotify /Notification Daemon |
| **文件路径** | `C:\Users\` | `/Users/` | `/home/` |
| **换行符** | CRLF (`\r\n`) | LF (`\n`) | LF (`\n`) |
| **原生对话框** | Win32 dialog | NSAlert / NSOpenPanel | GTK dialog / Zenity |
| **进程管理** | Task Manager | Activity Monitor | System Monitor / top |
| **自动启动** | 注册表 / 启动文件夹 | Login Items | systemd user service /.desktop |
| **托盘图标** | Windows Shell Tray | 菜单栏右侧 | 面板小程序/StatusNotifier |

**Windows 特有：**
- 高 DPI 缩放（DPI aware）
- UNC 网络路径
- 安装包 .exe / .msi

**macOS 特有：**
- 触控板手势支持
- 菜单栏常驻（Menu Bar App）
- Retina 高清屏支持
- 沙盒 App Store 签名

**Linux 特有：**
- 多发行版桌面环境差异（GNOME/KDE/XFCE）
- X11 vs Wayland 显示协议
- AppImage / Flatpak / Snap 多格式打包

## 3. 核心功能模块

### 3.1 消息流区域（跨平台一致）

消息流是所有平台的核心，布局适配不同屏幕：

**桌面端：消息流占左侧主区域，宽度弹性**

**手机端：消息流全屏，底部 Tab 切换功能**

**平板端：消息流居中，两侧留白或显示面板**

#### 3.1.1 消息类型

| 类型 | 图标 | 桌面端展示 | 手机端展示 |
|------|------|-----------|-----------|
| 文本消息 | 💬 | 行内展示 | 行内展示 |
| 代码消息 | 🤖 | 语法高亮 + 行号 + 文件标签 | 横向滚动 + 行号 |
| 文件消息 | 📎 | 行内预览 + 下载按钮 | 卡片式，Tap 展开 |
| 图片消息 | 🖼️ | 缩略图，Click 全屏 | 竖向列表，Tapped 放大 |
| Diff 消息 | ⟷ | 内联 Diff 卡片 | 折叠为摘要，Tap 展开 |
| 调试消息 | 🦊 | 调用堆栈 + 变量面板 | 跳转详情页 |
| 任务卡片 | ✅ | 勾选框 + 进度条 | 列表展示 |

#### 3.1.2 代码消息样式（桌面端）

```
┌─────────────────────────────────────────────────────────────┐
│ 💬 张三 · 11:23                                    [⋮ 更多] │
├─────────────────────────────────────────────────────────────┤
│ 能帮我 review 一下这段代码吗？                                │
│                                                                 │
│ ```typescript [src/agents/executor.ts]                       │

│                                                   [📋复制] [↗打开] │

**桌面端功能：**
- 行号显示
- 语法高亮（按语言着色）
- 右上角：复制、展开、在 IDE 中打开
- 宽度自适应面板

**手机端功能：**
- 横向滚动查看长行
- Tap 代码块放大为全屏视图
- 长按选择复制

## 10. 设计原则总结

| 原则 | 说明 |
|------|------|
| **聊天优先** | 所有功能融入消息流，不需要切换页面 |
| **AI 增强** | AI 理解代码上下文，不只是文档助手 |
| **场景隔离** | 金融/软件工程有独立 UI 模式和数据结构 |
| **可折叠** | 需要时展开 IDE，不需要时收起 |
| **实时协作** | 多人可以看到同一份代码、同一场调试 |
| **开发者友好** | 快捷键、低延迟、熟悉的工作流 |
| **移动优先** | 移动端体验完整，不只是降级版 |
| **响应式** | 布局自适应屏幕，内容按需呈现 |
