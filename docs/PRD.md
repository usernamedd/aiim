# AIIM 需求文档（PRD）

> 版本：v1.0 | 更新：2026-05-26
> 本文档用自然语言描述业务需求，不涉及技术实现细节。

---

## 一、账号与认证

### F01 用户注册

**需求描述**：用户通过邮箱和密码创建账号，以便使用平台服务。

**验收标准**：
- [ ] 用户输入有效邮箱和密码（≥8位）后可注册成功
- [ ] 邮箱已注册时返回明确错误提示
- [ ] 注册后自动登录并跳转主页

---

### F02 用户登录

**需求描述**：用户使用邮箱和密码登录，以便访问个人账号和聊天记录。

**验收标准**：
- [ ] 输入正确账号密码后即可登录
- [ ] 密码错误时提示"密码错误"
- [ ] 记住登录状态，下次打开无需重新登录

---

### F03 登出

**需求描述**：用户可以退出登录，以便在公共设备上保护隐私。

**验收标准**：
- [ ] 点击登出后清除登录状态
- [ ] 跳转至登录页面
- [ ] 本地缓存的聊天记录保留

---

## 二、即时消息

### F04 私聊

**需求描述**：用户可以与另一个用户进行一对一的实时文字沟通。

**验收标准**：
- [ ] 选择联系人后可发起私聊
- [ ] 发送消息后对方能实时收到
- [ ] 对方不在线时消息不会丢失，上线后能收到

---

### F05 消息状态

**需求描述**：用户需要知道发出的消息对方是否已收到、已读。

**验收标准**：
- [ ] 消息发送中显示 loading
- [ ] 对方收到后显示单个勾 ✓
- [ ] 对方已读后显示双勾 ✓✓（蓝色）
- [ ] 发送失败显示感叹号，可重发

---

### F06 群聊

**需求描述**：用户可以创建一个多人聊天群组，与多人同时沟通。

**验收标准**：
- [ ] 用户可创建群聊，设置群名
- [ ] 可邀请其他人加入群聊
- [ ] 群成员可以发送消息，所有成员都能看到
- [ ] 群主可修改群信息或解散群

---

### F07 消息历史

**需求描述**：用户可以查看与某人或某群的历史聊天记录。

**验收标准**：
- [ ] 进入聊天页面默认加载最新消息
- [ ] 向上滚动可加载更早的消息
- [ ] 消息按时间顺序排列，带日期分隔

---

## 三、联系人与好友

### F08 搜索用户

**需求描述**：用户可以通过用户名搜索找到其他用户。

**验收标准**：
- [ ] 输入用户名可搜索到匹配的用户
- [ ] 搜索结果展示用户名和头像

---

### F09 添加好友

**需求描述**：用户可以申请加其他用户为好友，好友通过后建立关系。

**验收标准**：
- [ ] 用户可向其他人发送好友申请
- [ ] 对方会收到申请通知
- [ ] 对方同意后成为好友，可直接发起私聊
- [ ] 对方拒绝后申请消失

---

### F10 好友列表

**需求描述**：用户可以查看所有好友及其在线状态。

**验收标准**：
- [ ] 好友列表展示所有已添加的好友
- [ ] 在线好友显示绿点，离线显示灰点
- [ ] 可点击好友直接发起私聊

---

### F11 好友申请管理

**需求描述**：用户可以查看、处理收到的好友申请。

**验收标准**：
- [ ] 有待处理申请时显示红点提示
- [ ] 可查看申请人的用户名和申请理由
- [ ] 可选择同意或拒绝

---

### F12 黑名单

**需求描述**：用户可将某人加入黑名单，加入后将不再收到对方的消息。

**验收标准**：
- [ ] 可将任意用户加入黑名单
- [ ] 黑名单中的人无法给你发消息
- [ ] 可随时将某人移出黑名单

---

### F13 联系人分组

**需求描述**：用户可以将好友分到不同分组（如同事、朋友、客户），便于管理。

**验收标准**：
- [ ] 可创建新的分组（如"同事"）
- [ ] 可将好友移入/移出分组
- [ ] 可按分组筛选查看好友

---

## 四、AI 智能体（Agent）

### F14 订阅行业 Agent

**需求描述**：平台预置软件工程、金融、医疗三个行业的 AI Agent，用户可直接订阅使用。

**验收标准**：
- [ ] 用户可查看平台提供的 Agent 列表
- [ ] 可订阅感兴趣的 Agent
- [ ] 订阅后在聊天列表中显示该 Agent，可直接对话

---

### F15 软件工程 Agent

**需求描述**：软件工程师订阅后，Agent 可帮助代码 Review、Bug 分析、生成 Commit 信息、查文档、写测试用例。

**验收标准**：
- [ ] 用户发送代码片段，Agent 可分析并给出建议
- [ ] 用户粘贴报错信息，Agent 可分析原因并给出修复方案
- [ ] 用户可让 Agent 生成规范的 Git Commit 信息

---

### F16 金融 Agent

**需求描述**：金融从业者订阅后，Agent 可帮助分析财报、查询行情、设置股票价格预警。

**验收标准**：
- [ ] 用户输入股票代码，Agent 可查询并展示基本信息
- [ ] 用户可设置价格预警（如"苹果跌破 $150 提醒我"）
- [ ] 条件触发时 Agent 主动推送消息

---

### F17 医疗 Agent

**需求描述**：医护人员订阅后，Agent 可帮助整理病历格式、查询药品相互作用、设置患者提醒。

**验收标准**：
- [ ] 用户输入症状描述，Agent 可整理成规范病历格式
- [ ] 用户输入多种药品名，Agent 可查询相互作用
- [ ] 用户可设置定时提醒（如"每天 9:00 提醒患者测血压"）

---

### F18 AI 辅助润色消息

**需求描述**：用户输入粗糙的聊天内容，AI 可帮用户润色成更专业的表述后再发送。

**验收标准**：
- [ ] 用户输入内容后，点击润色按钮
- [ ] AI 返回润色后的版本
- [ ] 用户确认后发送，或修改后再发

---

### F19 AI 辅助回复建议

**需求描述**：收到对方消息后，AI 可生成几条可能的回复建议，用户可一键发送或修改后再发。

**验收标准**：
- [ ] 收到消息后显示"AI 回复建议"按钮
- [ ] 点击后展示 2-3 条候选回复
- [ ] 点击任一条可直接发送

---

## 五、富文本消息

### F20 富文本消息

**需求描述**：用户发送的消息可以包含标题、列表、表格、代码块等富文本格式，让内容更易读。

**验收标准**：
- [ ] 用户可发送带格式的消息（标题/列表/表格）
- [ ] 接收方看到的消息保持原格式
- [ ] 代码块带语法高亮

---

### F21 快捷命令

**需求描述**：用户可以输入斜杠命令（/）来快速执行操作，如定时发送、查看队列。

**验收标准**：
- [ ] 输入 / 可弹出命令提示
- [ ] 支持 /schedule 定时发送（如 /schedule 14:00 "开会"）
- [ ] 支持 /queue 查看待发送消息队列

---

### F22 定时发送

**需求描述**：用户可以设置消息在指定时间自动发送。

**验收标准**：
- [ ] 用户可设置发送时间
- [ ] 消息加入队列，到时自动发送
- [ ] 用户可查看/取消待发送的消息

---

## 六、搜索

### F23 全局搜索

**需求描述**：用户可以在一个入口搜索聊天记录、联系人、群聊等内容。

**验收标准**：
- [ ] 输入关键词可搜索消息内容
- [ ] 搜索结果按类型分类（聊天/联系人/群聊）
- [ ] 点击结果可跳转到对应位置

---

## 七、行业切换

### F24 切换行业切面

**需求描述**：用户可以在不同行业视角（软件工程/金融/医疗/通用）之间切换，界面和功能随之调整。

**验收标准**：
- [ ] 用户可在设置中选择行业
- [ ] 切换后界面布局和默认功能相应变化
- [ ] 切换不影响聊天记录

---

## 八、个人设置

### F25 修改个人资料

**需求描述**：用户可以修改自己的昵称、头像、简介等信息。

**验收标准**：
- [ ] 可上传/更换头像
- [ ] 可修改昵称和简介
- [ ] 修改后立即生效

---

### F26 修改密码

**需求描述**：用户可以修改自己的登录密码。

**验收标准**：
- [ ] 需要验证当前密码
- [ ] 新密码需确认一次
- [ ] 修改后需重新登录

---

### F27 深色模式

**需求描述**：用户可以切换界面为深色/浅色主题。

**验收标准**：
- [ ] 可在设置中切换深色/浅色模式
- [ ] 切换后整个界面随之变化
- [ ] 记住用户偏好

---

**需求描述**：用户可以控制谁可以看到自己的在线状态。

**验收标准**：
- [ ] 可设置"所有人可见"或"仅好友可见"或"隐藏"
- [ ] 可查看谁看过自己的在线状态

---

### F29 消息通知设置

**需求描述**：用户可以控制是否接收新消息通知。

**验收标准**：
- [ ] 可开启/关闭新消息通知
- [ ] 可设置免打扰时间段
- [ ] 可设置锁屏通知是否显示内容

## 十、文件与媒体

### F30 发送图片

**需求描述**：用户可以发送图片给好友或群聊。

**验收标准**：
- [ ] 可从相册选择图片发送
- [ ] 图片显示缩略图，点击可放大
- [ ] 支持原图选项

---

**验收标准**：

- [ ] 显示语音波形图

## 十一、消息增强

### F33 消息反应

**需求描述**：用户可以对某条消息添加 emoji 反应（如 👍👏😂）。

**验收标准**：
- [ ] 长按消息可添加反应
- [ ] 消息下方显示所有反应及其数量
- [ ] 其他用户也可追加反应

---

### F34 引用回复

**需求描述**：用户可以引用某条消息进行回复，让对话更清晰。

**验收标准**：
- [ ] 点击引用按钮选择要回复的消息
- [ ] 发送时显示被引用消息的预览
- [ ] 点击引用可跳转到原消息

---

### F35 消息撤回

**需求描述**：用户可以撤回已发送的消息，撤回后对方看不到。

**验收标准**：
- [ ] 发送后 48 小时内可撤回
- [ ] 撤回后对方消息同步消失
- [ ] 显示"消息已撤回"提示

---

### F36 消息编辑

**需求描述**：用户可以编辑已发送消息的内容，编辑后对方看到的是新内容。

**验收标准**：
- [ ] 发送后一定时间内可编辑
- [ ] 编辑后对方看到新内容
- [ ] 显示"已编辑"标记

---

## 十二、群聊增强

### F37 群成员管理

**需求描述**：群主和管理员可以管理群成员（添加、移除、禁言）。

**验收标准**：
- [ ] 群主可添加管理员
- [ ] 管理员可移除普通成员
- [ ] 管理员可禁言/解禁成员

---

### F38 群公告

**需求描述**：群主或管理员可发布群公告，公告置顶显示。

**验收标准**：
- [ ] 管理员可发布/编辑群公告
- [ ] 公告在群聊顶部置顶显示
- [ ] 所有成员都能看到

---

### F39 群投票

**需求描述**：群内可以发起投票，群成员投票选择。

**验收标准**：
- [ ] 管理员可发起投票（如"周末去哪玩？"）
- [ ] 群成员可选择选项投票
- [ ] 投票结束后显示结果

---

## 需求优先级说明

| 优先级 | 含义 | 覆盖需求 |
|--------|------|---------|
| **P0** | 核心功能，无此功能 App 无法使用 | F01-F07 |
| **P1** | 重要功能，影响用户体验 | F08-F19 |
| **P2** | 增强功能，提升体验 | F20-F36 |
| **P3** | 锦上添花，可后续迭代 | F37-F39 |
