# P01: 登录页

> **版本:** v1.0 | **页面ID:** P01 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/login` |
| **目的** | 用户输入凭证（手机号/邮箱 + 密码）完成身份认证 |
| **前置条件** | 用户未登录 |

---

## 2. 组件层级（Tree Structure）

```
LoginPage
│
├── TopBar
│   └── C00 TopBar（简化版：仅返回按钮 + 标题）
│       └── BackButton（返回上一页）
│
├── LogoArea
│   ├── BrandLogo（品牌 Logo 图片）
│   └── BrandName（品牌名称）
│
├── LoginForm
│   ├── InputField_Phone
│   │   ├── C07 Button（类型切换：手机/邮箱）
│   │   └── C08 Input（输入框）
│   │
│   ├── InputField_Password
│   │   ├── C08 Input（密码输入框）
│   │   └── ShowPasswordToggle（显示/隐藏密码切换按钮）
│   │
│   ├── LinkButton_ForgotPassword
│   │   └── C07 Button（"忘记密码？" → 跳转 P03）
│   │
│   ├── PrimaryButton_Login
│   │   └── C07 Button（"登录"，主按钮样式）
│   │
│   └── Text_Link_Register
│       ├── C08 Text（"还没有账号？"）
│       └── C07 LinkButton（"去注册" → 跳转 P02）
│
├── Divider
│   └── C13 Divider（"或" 分隔线）
│
└── SocialLoginArea（可选）
    ├── SocialButton_Wechat
    │   └── C07 Button（微信图标 + "微信登录"）
    ├── SocialButton_Google
    │   └── C07 Button（Google 图标 + "Google 登录"）
    └── SocialButton_Apple
        └── C07 Button（Apple 图标 + "Apple 登录"）
```

**嵌套关系说明：**
- `LoginPage` → 根页面容器
  - `TopBar` → 顶部栏（LayoutComponent），C00 简化版
    - `BackButton` → 返回按钮（UIComponent）
  - `LogoArea` → Logo 区域（LayoutComponent），Flexbox 垂直排列
    - `BrandLogo` → Logo 图片（UIComponent）
    - `BrandName` → 品牌名（UIComponent）
  - `LoginForm` → 登录表单（FeatureComponent），核心交互区域
    - `InputField_Phone` → 手机/邮箱输入字段（FeatureComponent）
      - `Button` → 类型切换按钮（UIComponent）
      - `Input` → 输入框（UIComponent）
    - `InputField_Password` → 密码输入字段（FeatureComponent）
      - `Input` → 密码输入框（UIComponent）
      - `ShowPasswordToggle` → 显示/隐藏切换（UIComponent）
    - `LinkButton_ForgotPassword` → 忘记密码链接（UIComponent）
    - `PrimaryButton_Login` → 主登录按钮（UIComponent）
    - `Text_Link_Register` → 注册引导文本（LayoutComponent）
  - `Divider` → 分割线（UIComponent）
  - `SocialLoginArea` → 第三方登录区域（LayoutComponent）
    - `SocialButton_Wechat/Google/Apple` → 各第三方登录按钮（UIComponent）

## 3. 布局规范

```
┌──────────────────────────────────────┐
│  ← [TopBar: 返回按钮]                │
│                                      │
│            [Logo]                    │
│           AIIM                      │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 手机号 / 邮箱                   │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 密码（●●●●●●）       👁        │  │
│  └────────────────────────────────┘  │
│                                      │
│           忘记密码？                  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │           登录                  │  │
│  └────────────────────────────────┘  │
│                                      │
│      还没有账号？ 去注册              │
│                                      │
│────────────── 或 ──────────────────  │
│                                      │
│   [微信]   [Google]   [Apple]        │
│                                      │
└──────────────────────────────────────┘
```

- **布局方式：** 单列居中（max-width: 360px，水平居中）
- **垂直间距：** 各元素间 16px 间距
- **桌面端：** 居中展示，表单最大宽度 360px
- **移动端：** 全宽展示，两侧 24px padding
- **响应式：** 屏幕宽度 < 400px 时，SocialLoginArea 折叠为垂直排列

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **输入校验** | 手机号：11位数字；邮箱：有效邮箱格式；密码：≥8位 |
| **登录按钮点击** | 显示 Loading → 调用登录 API → 成功跳转 P10 / 失败显示 Toast |
| **"忘记密码"点击** | 跳转 P03（忘记密码页） |
| **"去注册"点击** | 跳转 P02（注册页） |
| **第三方登录点击** | 唤起对应 SDK 授权 |
| **密码可见切换** | 点击 Toggle 图标切换密码明文/密文显示 |
| **Enter 键提交** | 在密码框按 Enter 触发登录 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **InputField_Phone** | Normal | 默认 placeholder "请输入手机号或邮箱" |
| | Focus | 边框高亮（品牌色） |
| | Error | 红色边框 + 下方错误提示文字 |
| **InputField_Password** | Normal | 默认显示 ●●●●●●●● |
| | Show | 点击后显示明文 |
| | Error | 红色边框 + 下方错误提示文字 |
| **PrimaryButton_Login** | Normal | 主色填充 |
| | Hover | 颜色加深 10% |
| | Loading | 显示 C12 LoadingSpinner，禁用点击 |
| | Disabled | 灰色，不可点击（输入为空时） |
| **SocialLoginArea** | Normal | 显示第三方登录按钮 |
| | Hidden | 一键登录等特殊场景下隐藏 |
