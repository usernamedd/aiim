# P31: 调试控制台页

> **版本:** v1.0 | **页面ID:** P31 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/debug`（独立页面）或作为 MultiPanel 内 Tab（`P20/P21 MultiPanel → DebugTab`） |
| **目的** | 嵌入式调试控制台，支持断点管理、变量查看、调用栈追踪、控制台输出 |
| **前置条件** | 用户已登录，进入软件工程切面，项目已启动调试会话 |

**嵌套关系说明：**
- `DebugConsolePage` → 根页面容器
  - `TopBar` → 顶部栏（C00）
  - `DebugToolbar` → 调试工具栏（FeatureComponent）
    - `ControlGroup` → 运行控制组
    - `StepGroup` → 单步执行组
    - `WatchGroup` → 监视组
  - `MainContent` → 主内容区（LayoutComponent，横向三栏）
    - `CallStackPanel` → 调用栈面板（FeatureComponent）
      - `StackFrame × N` → 调用栈帧（FeatureComponent）
    - `SourceViewer` → 源码查看器（FeatureComponent）
      - `TabBar` → 源码 Tab 栏
      - `SourceContent` → 源码内容
        - `BreakpointGutter` → 断点栏
        - `SourceLines` → 源代码行
    - `VariablesPanel` → 变量面板（FeatureComponent）
      - `ScopeSection × N` → 作用域分组
        - `VariableItem × N` → 变量项（可展开对象）
      - `WatchSection` → 监视表达式区
  - `ConsolePanel` → 控制台面板（FeatureComponent，可折叠）
    - `LogEntry × N` → 日志条目

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **点击行号左侧** | 设置/取消断点 |
| **断点右键** | 编辑断点条件/禁用/删除 |
| **点击 StackFrame** | 切换当前帧，SourceViewer 跳转到对应文件和行 |
| **展开变量对象** | 点击 ▶ 展开，显示子属性 |
| **编辑变量值** | 双击 PrimitiveValue → 进入编辑模式 |
| **添加监视表达式** | 点击 👁+ → 输入表达式 → 添加到 WatchSection |
| **控制台日志点击对象** | 展开显示对象详细信息 |
| **过滤日志级别** | 点击 Info/Warn/Error 过滤日志 |
| **单步调试** | Step Over/Into/Out 按钮控制程序执行 |
| **条件断点** | 右键断点 → 输入条件表达式 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **SessionIndicator** | Running | 绿色 ●，RunButton 可用，PauseButton 可用 |
| | Paused | 黄色 ●，RunButton 可用，Step 按钮可用 |
| | Stopped | 灰色 ●，所有调试按钮禁用 |
| **BreakpointMarker** | Active | 红色实心 ● |
| | Disabled | 红色空心 ○ |
| | Conditional | 红色 ● + 问号badge |
| | CurrentLine | 蓝色背景高亮 |
| **VariableItem** | Collapsed | ▶ 图标，对象显示为 "{...}" |
| | Expanded | ▼ 图标，展开显示所有属性 |
| **ConsolePanel** | Collapsed | 只显示 Header，高度 36px |
| | Expanded | 展开显示日志列表 |
| **LogEntry** | Info/Warn/Error/Debug | 不同颜色图标 |
