# P50: 个人设置页

> **版本:** v1.0 | **页面ID:** P50 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/settings` |
| **目的** | 管理账号信息、应用设置、隐私选项 |
| **前置条件** | 用户已登录 |

**嵌套关系说明：**
- `SettingsPage` → 根页面容器
  - `TopBar` → 顶部栏（C00）
  - `SettingsList` → 设置列表（LayoutComponent）
    - `AccountSection` → 账号分组
      - `ProfileItem` → 头像昵称项（FeatureComponent，整行可点击）
      - `PhoneItem/EmailItem/PasswordItem` → 各信息项（UIComponent）
    - `AppearanceSection` → 外观分组
      - `ThemeItem` → 主题项（FeatureComponent）
      - `FontSizeItem` → 字体大小项（FeatureComponent）
      - `LanguageItem` → 语言项（UIComponent）
    - `NotificationSection` → 通知分组
      - `PushNotificationItem/VoiceNotificationItem` → 开关项（FeatureComponent）
      - `MessageSoundItem/DoNotDisturbItem` → 选择项（UIComponent）
    - `PrivacySection` → 隐私分组
      - `OnlineStatusItem/ReadReceiptItem/LastSeenItem` → 开关/选择项
    - `DomainSection` → 行业切面分组
      - `DomainSwitcherItem` → 切面切换项（FeatureComponent）
    - `DataSection` → 数据管理分组
      - `StorageItem` → 存储空间项（FeatureComponent）
      - `CacheItem` → 清理缓存项（FeatureComponent）
    - `AboutSection` → 关于分组
      - `VersionItem/TermsItem/PrivacyItem/LicensesItem` → 各信息项
    - `DangerZone` → 危险操作分区
      - `LogoutButton` → 退出登录按钮（UIComponent）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **点击 ProfileItem** | 跳转编辑个人资料页（头像/昵称/签名） |
| **点击 PhoneItem/EmailItem** | 跳转验证身份后修改 |
| **点击修改密码** | 跳转 P03 忘记密码页（或单独修改密码页） |
| **切换主题** | 选择 深色/浅色/跟随系统 → 实时预览 → 确认 |
| **调节字体大小** | 拖动 Slider → 实时预览 |
| **切换通知开关** | 点击 Toggle → 开启/关闭 → Toast 确认 |
| **点击切面切换** | 跳转 P51 切面切换页 |
| **清理缓存** | 点击"清理" → 显示 Loading → 清理完成 Toast |
| **退出登录** | 点击 → 确认对话框 → 退出 → 跳转 P01 |
| **注销账号** | 点击 → 二次确认（输入密码）→ 注销 → 跳转 P01 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **ToggleSwitch** | ON | 主色 Track，Thumb 在右侧 |
| | OFF | 灰色 Track，Thumb 在左侧 |
| **SliderControl** | Normal | 拖动中Thumb放大 |
| | Disabled | 灰色，不可拖动 |
| **ThemeItem** | Dark | 显示深色圆形预览 |
| | Light | 显示浅色圆形预览 |
| | System | 显示系统图标 |
| **StorageItem** | Normal | 显示使用量和进度条 |
| | Full | 进度条红色警告 |
