# P03: 忘记密码页

> **版本:** v1.0 | **页面ID:** P03 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/forgot-password` |
| **目的** | 用户通过手机号/邮箱验证后重置密码 |
| **前置条件** | 用户未登录，且需要找回密码 |

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **验证码发送** | 调用发送验证码 API，发送到已注册的手机号/邮箱 |
| **验证码输入** | 6位自动触发验证，与 P02 相同逻辑 |
| **密码重置提交** | Loading → 调用重置密码 API → 成功显示"密码重置成功" → 跳转 P01 |
| **新密码校验** | 不能与原密码相同 |
| **"去登录"点击** | 跳转 P01 登录页 |

---

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **StepContent** | Step1/2/3 | 同 P02 三步骤逻辑 |
| **VerifyCodeInput** | Empty/Partial/Complete/Error | 同 P02 |
| **PasswordStrengthIndicator** | Weak/Medium/Strong | 同 P02 |
| **Reset Success** | Success | 显示成功提示 → 3秒后跳转 P01 |

---

## 7. 与 P02 注册页的差异

| 差异点 | P02 注册页 | P03 忘记密码页 |
|--------|-----------|---------------|
| **TopBar 标题** | "注册" | "找回密码" |
| **Step1 按键文案** | "获取验证码" | "下一步" |
| **Step3 最终动作** | 完成注册，跳转 P10 | 确认重置，跳转 P01 |
| **Step3 提示文案** | "请设置密码" | "请设置新密码" |
| **协议文本** | "注册即同意《用户协议》《隐私政策》" | 无（已在注册时同意） |
| **底部链接** | "还没有账号？去注册" | "想起密码了？去登录" |
