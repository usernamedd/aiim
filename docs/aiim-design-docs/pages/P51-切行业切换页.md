# P51: 切行业切换页

> **版本:** v1.0 | **页面ID:** P51 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/settings/domain` |
| **目的** | 切换当前行业切面（软件工程/金融研究/医疗/通用等），切换后重新加载对应行业功能 |
| **前置条件** | 用户已登录，从 P50 设置页"切换切面"入口进入 |

---

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **点击 DomainItem** | 若非当前行业 → 弹出确认对话框 → 切换 → Loading → 重新加载 → 跳转 P10 |
| **点击当前行业** | 无操作，不显示确认框 |
| **切换完成** | Toast "已切换到 {行业名}"，更新全局状态 |
| **返回按钮** | 返回 P50 设置页 |

---

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **DomainItem** | Current（当前行业） | 显示 ✓ 选中标记，整行高亮背景 |
| | Available（可切换） | 默认样式，Hover 时背景变浅 |
| | Hover | 背景色变浅（桌面端） |
| | Active | 按下时背景色更深 |
| **CurrentDomainBanner** | Normal | 显示当前行业图标和名称 |
