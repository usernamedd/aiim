# P40: 仪表盘页（金融研究切面）

> **版本:** v1.0 | **页面ID:** P40 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/dashboard`（独立页面）或作为 MultiPanel 内 Tab（`P20/P21 MultiPanel → DashboardTab`） |
| **目的** | 展示投资组合概览、市场行情、持仓收益一览 |
| **前置条件** | 用户已登录，进入金融研究切面 |

**嵌套关系说明：**

    - `TotalValueCard` → 总资产卡片（FeatureComponent）
    - `TodayPLCard` → 今日盈亏卡片（FeatureComponent）
    - `MonthPLCard` → 本月收益卡片（FeatureComponent）
    - `AssetAllocationCard` → 资产配置卡片（FeatureComponent）
  - `MarketOverview` → 市场行情区（LayoutComponent）
    - `IndexGrid` → 指数卡片网格（LayoutComponent）
      - `IndexCard × N` → 各指数卡片（FeatureComponent）
  - `HoldingsList` → 持仓列表（LayoutComponent）
    - `HoldingItem × N` → 持仓项（FeatureComponent）
  - `RecentTransactions` → 近期交易记录（LayoutComponent）
    - `TransactionItem × N` → 交易记录项（FeatureComponent）
  - `FAB` → 悬浮交易按钮（UIComponent）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **点击 HoldingItem** | 跳转 `/stock/:symbol`（P41 持仓详情页） |
| **点击 IndexCard** | 查看指数详情（跳转 P41 或弹窗） |
| **点击 StarButton** | 收藏/取消收藏股票，更新自选列表 |
| **切换日期** | 选择日期 → 刷新该日期的收益数据 |
| **下拉刷新** | 刷新所有数据（仪表盘通用） |
| **点击 FAB** | 跳转交易下单页面（待设计） |
| **查看全部交易** | 跳转交易记录列表页（待设计） |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **ChangeInfo** | Positive | 绿色 ▲ + 绿色金额 |
| | Negative | 红色 ▼ + 红色金额 |
| | Neutral | 灰色 — |
| **IndexCard** | Rising | 绿色文字 |
| | Falling | 红色文字 |
| **HoldingItem** | Normal | 默认显示 |
| | Starred | 显示 ⭐ 实心 |
| | Unstarred | 显示 ⭐ 空心 |
| **FAB** | Visible | 显示交易按钮 |
| | Hidden | 滚动时自动隐藏 |
