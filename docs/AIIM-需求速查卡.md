# AIIM 需求速查卡

> 一页记住整套需求体系。详细版见 `AIIM-需求组织地图.md`，需求原文见 `PRD.md`。

## 三个字母的含义

| 符号 | 含义 | 在哪 |
|------|------|------|
| **D** | 功能域（D1-D11），需求的**唯一归属** | 组织地图 |
| **F** | 已定需求（F01-F44），有需求描述 + 验收标准 | PRD + 地图 |
| **G** | 行业缺口候选（41 项），只是候选，没写验收标准 | 只有地图 |
| **P** | 优先级 P0（核心）/ P1 / P2 / P3 | 横切标签 |

规则：**F 只增不改编号**；新需求成熟 → G 升级为 F；PRD 的章节只是排列顺序，**归属看域**。

## 四条横切轴（不占归属，可叠加）

消息生命周期 · 产品优先级 · 用户角色 · 端（桌面/Android/iOS/后端）

## 三个最常问的问题，答案在这

- 这条需求归哪？→ 看 D，不看 PRD 章节。
- 这个功能做了吗？→ 有 F 编号 = 进了需求池；只有 G 编号 = 还没定。
- 新需求怎么加？→ PRD 末尾追加 `### F45 xxx`（描述 + 验收 checklist）→ 同步优先级表 → 地图归位 → commit。
