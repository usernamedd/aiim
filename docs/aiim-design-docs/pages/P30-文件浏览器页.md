# P30: 文件浏览器页

> **版本:** v1.0 | **页面ID:** P30 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/files`（独立页面）或作为 MultiPanel 内 Tab（`P20/P21 MultiPanel → FileExplorerTab`） |
| **目的** | 浏览项目目录结构，预览文件内容，支持文件树交互操作 |
| **前置条件** | 用户已登录，进入软件工程切面 |

**嵌套关系说明：**
- `FileExplorerPage` → 根页面容器
  - `TopBar` → 顶部栏（C00）
    - `MoreButton` → 更多选项（FeatureComponent，包含多个子菜单项）
  - `Toolbar` → 操作工具栏（LayoutComponent）
    - `Breadcrumb` → 路径导航（FeatureComponent）
      - `PathSegment × N` → 路径段（UIComponent），可点击跳转目录
    - `ViewModeToggle` → 视图切换（FeatureComponent）
    - `NewFileButton/NewFolderButton` → 新建按钮（UIComponent）
  - `FileTree` → 文件树（FeatureComponent，核心组件）
    - `TreeNode × N` → 树节点（FeatureComponent，递归结构）
      - `FileIcon` → 根据文件类型显示不同图标
      - `GitStatusBadge` → Git 状态标签（UIComponent）
      - `ChildrenContainer` → 子节点容器（LayoutComponent），递归嵌套
  - `FilePreview` → 文件预览区（FeatureComponent）
    - `PreviewHeader` → 预览头部（LayoutComponent）
      - `FileTab × N` → 多文件 Tab（UIComponent）
    - `CodeViewer` → 代码预览器（FeatureComponent）
      - `LineNumbers` → 行号列（UIComponent）
      - `CodeContent` → 代码内容（FeatureComponent，含语法高亮）
    - `ImageViewer` → 图片预览器（FeatureComponent）
    - `TextViewer` → 文本预览器（FeatureComponent）
  - `EmptyState` → 空状态占位（C11）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **点击文件夹** | 展开/折叠子节点，更新 Breadcrumb |
| **点击文件** | 在预览区显示文件内容（CodeViewer/ImageViewer/TextViewer） |
| **点击 Breadcrumb 路径段** | 跳转到对应目录 |
| **双击文件** | 新窗口/新 Tab 打开（在 MultiPanel 场景下） |
| **右键点击节点** | 显示右键菜单（新建/重命名/删除/复制路径） |
| **拖拽文件** | 拖拽移动文件到其他目录 |
| **查看 Git 状态** | 显示文件的新增/修改/删除状态 |
| **代码折叠** | 点击折叠图标收起代码块 |
| **图片缩放** | 滚轮缩放，支持拖拽平移 |
| **新建文件/文件夹** | 弹出输入框 → 输入名称 → 创建 |
| **文件 Tab 操作** | 点击 Tab 切换预览，点击 × 关闭 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **TreeNode** | Collapsed | 显示 ▶ 图标，子节点隐藏 |
| | Expanded | 显示 ▼ 图标，子节点展开 |
| | Selected | 高亮背景，显示预览 |
| | Hover | 背景色加深（桌面端） |
| **GitStatusBadge** | New | 🔵 "N" 蓝色标签 |
| | Modified | 🟡 "M" 黄色标签 |
| | Deleted | 🔴 "D" 红色标签 |
| | Unmodified | 无标签 |
| **CodeViewer** | Loading | 显示 LoadingSpinner |
| | Loaded | 显示代码内容 |
| | Error | 显示"文件加载失败" |
| **ImageViewer** | Normal | 原始尺寸显示 |
| | Zoomed | 放大显示，可拖拽 |
