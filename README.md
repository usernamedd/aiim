# AIIM - AI-Native Instant Messenger

> AI 是核心功能，不是附加功能

## 产品定位

AIIM（AI Instant Messenger）是一个 **AI-Native 的即时通讯平台**。

区别于传统 IM（AI 是 chatbot 插件），AIIM 的核心理念是：**AI 深度融入通讯的每一个环节**，帮助用户更高效地处理信息、表达观点、管理知识。

---

## 核心能力

### 🤖 行业专属 AI 智能体

预置三大行业 Agent，用户也可自建：

| Agent | 定位 | 核心能力 |
|-------|------|---------|
| **软件工程 Agent** | 程序员必备 | 代码 Review、Commit 生成、Bug 分析、文档查询 |
| **金融 Agent** | 金融从业者 | 财报分析、行情摘要、风险预警、投资报告 |
| **医疗 Agent** | 医护人员 | 病历整理、处方建议、药品交互、文献查询 |

### ✏️ AI 辅助消息编辑

- **润色发送**：输入粗糙内容 → AI 整理/润色 → 富文本格式发送
- **回复建议**：AI 生成多条回复选项 → 一键发送或修改
- **富文本编辑器**：可视化编辑，**不需要写 Markdown**

### ⏰ 智能消息调度

- 消息排队、定时发送、延迟发送
- 条件触发（如「行情突破 3000 点时」自动发提醒）
- 批量发送、发送模板

### 🎯 Telegram Bot 式命令系统

- 斜杠命令（`/send`, `/schedule`, `/agent`）
- Agent 自定义命令（如 `/stock 苹果`）
- Inline 查询（`@AgentName 查询内容`）
- 快捷按钮（消息下的操作按钮）

### 📎 多模态输入

语音 / 图片 / 文件 → 直接丢给 AI 处理 → 生成结果或发送

## 技术选型

| 平台 | 语言 | 框架 | UI |
|------|------|------|-----|
| Android | Kotlin | Jetpack Compose | Material 3 |
| iOS | Swift | SwiftUI | SwiftUI |
| 桌面端 | TypeScript | Tauri | React + CSS |
| 后端 | Go | Gin + GORM | - |

| 组件 | 技术 |
|------|------|
| 数据库 | SQLite（开发）→ PostgreSQL（生产） |
| 实时通讯 | WebSocket |
| AI 接入 | OpenAI GPT-4o / Claude 3.5 / 本地模型 |
| 富文本渲染 | Markdown + 可视化编辑器 |
| 端对端加密 | Signal 协议 |
