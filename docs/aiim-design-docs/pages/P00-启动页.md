# P00: 启动页

> **版本:** v1.0 | **页面ID:** P00 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/`（App 冷启动） |
| **目的** | 展示品牌 Logo，等待初始化完成，引导用户进入主页面或登录页 |
| **前置条件** | 无（未登录/已登录均显示此页） |

---

## 2. 组件层级（Tree Structure）

```
LaunchPage
│
├── LaunchBackground
│   └── BrandLogo
│       ├── LogoIcon（Logo 图片/SVG）
│       └── BrandName（品牌名称文字）
│
└── LoadingIndicator
    └── C12 LoadingSpinner
```

**嵌套关系说明：**
- `LaunchPage` → 根页面容器（Page 级别）
  - `LaunchBackground` → 背景层（LayoutComponent），负责全屏背景渲染
    - `BrandLogo` → 品牌标识组件（FeatureComponent），内含 Logo 图标和品牌名
  - `LoadingIndicator` → 加载指示器（UIComponent），复用全局 C12 LoadingSpinner

---

## 3. 布局规范

```
┌──────────────────────────────────────┐
│                                      │
│            [Logo 图片]               │
│                                      │
│           AIIM                       │
│                                      │
│                                      │
│            ◌ (加载动画)              │
│                                      │
└──────────────────────────────────────┘
```

- **桌面端：** 居中展示，Logo 尺寸 120×120px，品牌名 24px
- **移动端：** 居中展示，全屏沉浸式，Logo 尺寸 100×100px，品牌名 20px
- **布局方式：** Flexbox 居中（justify-content: center, align-items: center）
- **背景：** 品牌渐变色或纯色（由品牌规范定义）

---

## 4. 组件分类

| 组件ID | 组件名称 | 类型 | 说明 |
|--------|---------|------|------|
| - | LaunchPage | Page | 路由级别页面容器 |
| - | LaunchBackground | LayoutComponent | 全屏背景布局 |
| - | BrandLogo | FeatureComponent | 品牌标识（Logo + 名称） |
| - | LogoIcon | UIComponent | Logo 图片/SVG |
| - | BrandName | UIComponent | 品牌名称文字 |
| C12 | LoadingSpinner | UIComponent | 全局加载指示器（复用） |

---

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **初始化完成（已登录）** | 自动跳转 `/`（主聊列表页 P10） |
| **初始化完成（未登录）** | 自动跳转 `/login`（登录页 P01） |
| **加载超时（>10s）** | 显示"网络异常，点击重试"提示 |

---

## 6. 状态

| 状态 | 表现 |
|------|------|
| **Loading** | Logo + 加载动画持续显示 |
| **Error** | 显示错误提示 + 重试按钮 |
| **Redirecting** | 隐藏加载动画，准备跳转 |

---

## 7. 复用说明

- 本页为独立页面，无跨页面复用组件
- `LoadingSpinner` 为全局组件 C12，在其他页面复用
