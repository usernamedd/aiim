# AIIM 需求组织地图 v2（域 → 模块 → 功能点 三层结构）

> 版本：v2.0 | 更新：2026-10-08
> 主轴 = **功能域**（唯一归属）；其余四维（消息生命周期 / 产品优先级 / 用户角色 / 端）为**横切切片轴**。
> 术语：域/模块/功能点 = L1/L2/L3；跨域标签 = 横切关注点(cross-cutting concern)；轴上取值 = 需求属性(attribute)。
> 优先级列沿用 PRD 的 P0-P3。

---

## 0. 三层结构与四根横切轴

```
L1  功能域 (主轴, canonical)       ← 11 个域，唯一归属
L2  功能模块 / 子域                ← 域下的分组
L3  功能点 / 能力 (Feature)        ← F 编号主要落点
L4  需求条目 / 验收规则             ← PRD 每条需求的验收 checklist

横切轴: 消息生命周期 · 产品优先级 · 用户角色 · 端（每条 L3 都可打这四个标签）
```
