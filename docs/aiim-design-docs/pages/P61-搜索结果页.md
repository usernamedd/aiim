# P61: 搜索结果页

> **版本:** v1.0 | **页面ID:** P61 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/search/results`（或作为 P60 内的内嵌结果页面） |
| **目的** | 展示搜索结果的详细内容视图，支持多维度筛选和排序，当搜索结果较多时从 P60 跳转进入详情 |
| **前置条件** | 用户已登录，已在 P60 输入搜索关键词并跳转 |

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **点击编辑搜索词** | 返回 P60，保留搜索词 |
| **展开/收起高级筛选** | 点击 Toggle → 展开/收起 FilterPanel |
| **选择筛选条件** | 实时更新结果（debounce） |
| **切换排序方式** | 选择后重新排序结果 |
| **点击消息结果** | 跳转 P20/P21 对应会话，滚动到该消息位置 |
| **点击文件结果** | 跳转 P30 预览该文件 |
| **点击联系人** | 跳转 P20 发起私聊 |
| **点击代码行号** | 跳转 P30/P31，定位到对应文件和行 |
| **加载更多** | 追加加载下一页结果 |
| **分页切换** | 跳转对应页码，滚动到顶部 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **AdvancedFilters** | Collapsed | 显示 ToggleButton，FilterPanel 隐藏 |
| | Expanded | FilterPanel 展开显示 |
| **ResultGroup** | Expanded | 显示全部结果 |

| | GridView | 卡片网格显示 |
| **Pagination** | HasPrev | 上一页按钮可用 |
| | NoPrev | 上一页按钮禁用 |
| | HasNext | 下一页按钮可用 |
| | NoNext | 下一页按钮禁用 |

## 7. 与 P60 全局搜索页的差异

| 差异点 | P60 全局搜索页 | P61 搜索结果页 |
|--------|---------------|---------------|
| **定位** | 搜索入口页面 | 结果详情页面 |
| **搜索输入** | 有搜索输入框 | 无（只显示关键词） |
| **筛选** | 基础 Tab 筛选 | 高级筛选面板（可折叠） |
| **排序** | 无排序选项 | 多种排序方式 |
| **结果展示** | 分组显示少量结果 | 分组分页完整结果 |
| **分页** | 无分页 | 有分页导航 |
| **展开/收起** | 无 | 各结果组可展开/收起 |
