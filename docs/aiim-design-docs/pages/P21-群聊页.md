# P21: 群聊页

> **版本:** v1.0 | **页面ID:** P21 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/group/:groupId` |
| **目的** | 群组多人实时聊天，支持 @成员、群公告等群组特有功能 |
| **前置条件** | 用户已登录，为群组成员，从 P10 群组列表点击进入 |

**嵌套关系说明：**
- `GroupChatPage` → 根页面容器（继承 P20 私聊页大部分结构）
  - `TopBar` → 顶部栏（C00）
    - `GroupInfo` → 群组信息区（FeatureComponent）
    - `GroupInfoButton` → 群信息入口按钮（UIComponent）
  - `MessageList` → 消息列表（FeatureComponent）
    - `GroupNoticeBubble` → 群公告气泡（FeatureComponent，特有）
    - `MessageBubble` → 消息气泡（FeatureComponent，同 P20，但左侧显示 SenderName）
    - `AtMessageIndicator` → @我消息指示器（UIComponent）
    - `TypingIndicator` → 正在输入提示（同 P20）
  - `MultiPanel` → 多功能面板（C03）
    - 新增 `MemberListTab`（群成员列表）
  - `InputBar` → 输入栏（C04）
    - 新增 `AtButton` → @ 提及按钮
    - `AtMemberTag` → @ 选中成员标签

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **@ 提及成员** | 点击 @ 按钮 → 弹出成员选择器 → 选择成员 → 显示 @标签 → 发送后对方收到高亮通知 |
| **查看群公告** | 点击公告气泡 → 展开完整公告内容 |
| **群信息面板** | 点击 ℹ 按钮 → 从右侧滑出群信息面板（含群名称/头像/成员/公告等） |
| **@我指示器** | 有 @ 我的消息时顶部显示指示条，点击滚动到对应消息 |
| **设置群公告** | 群主/管理员长按自己的消息 → 显示"设为群公告"选项 |
| **禁言用户** | 群主/管理员在成员列表点击成员 → 选择禁言 |
| **其他行为** | 与 P20 私聊页一致（发送消息/文件/图片等） |

## 7. 与 P20 私聊页的差异

| 差异点 | P20 私聊页 | P21 群聊页 |
|--------|-----------|-----------|
| **TopBar** | 显示对方昵称+状态 | 显示群名+成员数+在线数 |
| **MessageBubble** | 对方气泡不显示昵称 | 对方气泡显示昵称（SenderName） |
| **GroupNoticeBubble** | 无 | 有群公告气泡置顶显示 |
| **AtMessageIndicator** | 无 | 有 @我消息指示器 |
| **MultiPanel Tab** | 4个（文件/调试/差异/AI） | 5个（+成员列表） |
| **InputBar** | 无 @ 按钮 | 有 @ 按钮 + AtMemberTag |
| **TypingIndicator** | 显示"对方正在输入" | 显示"张三 正在输入..." |
