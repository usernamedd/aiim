# P02: 注册页

> **版本:** v1.0 | **页面ID:** P02 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/register` |
| **目的** | 新用户注册 AIIM 账号（手机号/邮箱注册流程） |
| **前置条件** | 用户未登录 |

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **获取验证码点击** | 调用发送验证码 API → 显示倒计时 60s → 倒计时结束可重发 |
| **验证码自动跳转** | 输入一位数字后自动聚焦下一位 |
| **删除验证码** | 删除一位后自动回退到上一位 |
| **密码强度检测** | 实时检测，≥8位含字母+数字+特殊字符为"强" |
| **注册按钮点击** | Loading → 调用注册 API → 成功跳转 P10 / 失败 Toast |
| **协议链接点击** | 新窗口打开用户协议/隐私政策页面 |
| **返回按钮点击** | 若 Step > 1，退回上一步；否则返回上一页 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **StepsIndicator** | Step1/2/3 | 对应步骤圆点高亮，已完成步骤显示 ✓ |
| **VerifyCodeInput** | Empty | 6个方框为空 |
| | Partial | 部分方框已输入 |
| | Complete | 6位全部输入，自动触发验证 |
| | Error | 验证码错误，方框变红 |
| **PasswordStrengthIndicator** | Weak | 红色条，标签"弱" |
| | Medium | 黄色条，标签"中" |
| | Strong | 绿色条，标签"强" |
| **PrimaryButton_Register** | Disabled | 输入不完整时灰色 |
| | Enabled | 输入完整时主色可点击 |
