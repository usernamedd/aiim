# P60: 全局搜索页

> **版本:** v1.0 | **页面ID:** P60 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/search` |
| **目的** | 统一搜索消息、文件、联系人、代码等所有内容，支持多类型过滤和时间范围筛选 |
| **前置条件** | 用户已登录，从 TopBar 搜索按钮进入 |

**嵌套关系说明：**
- `GlobalSearchPage` → 根页面容器
  - `TopBar` → 专用搜索顶部栏（LayoutComponent）
    - `SearchHeader` → 搜索头部组件
      - `SearchInputContainer` → 搜索输入容器（LayoutComponent）
        - `SearchIcon` → 搜索图标（UIComponent）
        - `Input` → 搜索输入框（UIComponent，C08）
        - `ClearButton` → 清除按钮（UIComponent）
      - `CancelButton` → 取消按钮（UIComponent）
  - `SearchFilters` → 搜索过滤器（LayoutComponent）
    - `FilterTabBar` → Tab 过滤栏（FeatureComponent）
      - `FilterTab_All/Messages/Files/Contacts/Code` → 各过滤 Tab（UIComponent）
    - `FilterOptions` → 扩展过滤选项（LayoutComponent，可折叠）
  - `SearchResults` → 搜索结果区（LayoutComponent）
    - `RecentSearchesSection` → 最近搜索（FeatureComponent）
      - `RecentItem × N` → 最近搜索项（UIComponent）
    - `SuggestedSearchesSection` → 推荐搜索（FeatureComponent）
    - `ResultSection_Messages` → 消息结果分组（LayoutComponent）
      - `ResultItem_Message × N` → 消息结果项（FeatureComponent）
    - `ResultSection_Files` → 文件结果分组（LayoutComponent）
      - `ResultItem_File × N` → 文件结果项（FeatureComponent）
    - `ResultSection_Contacts` → 联系人结果分组（LayoutComponent）
      - `ResultItem_Contact × N` → 联系人结果项（FeatureComponent）
    - `ResultSection_Code` → 代码结果分组（LayoutComponent）
      - `ResultItem_Code × N` → 代码结果项（FeatureComponent）
    - `NoResultsState` → 无结果状态（C11 EmptyState）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **输入搜索** | 实时搜索（debounce 300ms）或按 Enter 触发 |
| **点击最近搜索** | 填充到搜索框并执行搜索 |
| **删除最近搜索** | 点击 × → 从历史中移除该条 |
| **切换过滤 Tab** | 点击 Tab → 只显示该类型结果 |
| **点击结果项** | 消息：跳转 P20/P21 对应会话并定位到该消息 |
| | 文件：跳转 P30 预览该文件 |
| | 联系人：跳转 P22 聊天或 P20 私聊 |
| | 代码：跳转 P30/P31 定位到对应文件和行号 |
| **ESC 取消** | 关闭搜索页，返回上一页 |
| **清除搜索** | 点击 × → 清空输入 → 显示最近搜索 |
| **代码高亮点击** | 跳转文件并滚动到对应行 |
