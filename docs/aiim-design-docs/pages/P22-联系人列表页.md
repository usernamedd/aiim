# P22: 联系人列表页

> **版本:** v1.0 | **页面ID:** P22 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/contacts` |
| **目的** | 管理好友列表和群组列表，支持搜索、添加、分组浏览 |
| **前置条件** | 用户已登录 |

---

**嵌套关系说明：**
- `ContactsPage` → 根页面容器
  - `TopBar` → 顶部栏（C00）
    - `AddButton` → 添加按钮（UIComponent）
  - `TabBar` → Tab 切换栏（FeatureComponent）
    - `FriendsTab` → 好友 Tab
    - `GroupsTab` → 群组 Tab
  - `TabContent` → Tab 内容区（LayoutComponent）
    - `FriendsTab Content` → 好友列表内容
      - `SearchBar` → 搜索栏（FeatureComponent）
      - `FriendRequestBanner` → 好友申请横幅（FeatureComponent）
      - `SectionList` → 字母分组列表（LayoutComponent）
        - `Section_A/B/C.../#` → 各字母分组
          - `SectionIndex` → 字母索引标题（UIComponent）
          - `FriendItem × N` → 好友列表项（FeatureComponent）
    - `GroupsTab Content` → 群组列表内容
      - `CreateGroupButton` → 创建群组按钮（UIComponent）
      - `GroupItem × N` → 群组列表项（FeatureComponent）
  - `SectionIndexer` → 右侧字母索引导航（UIComponent），快速定位
  - `FAB` → 悬浮操作按钮（UIComponent）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **好友搜索** | 输入关键词 → 实时过滤列表，只显示匹配好友 |
| **点击 FriendItem** | 跳转 `/chat/:userId`（P20 私聊页） |
| **点击 GroupItem** | 跳转 `/group/:groupId`（P21 群聊页） |
| **好友申请横幅点击** | 跳转好友申请列表页（待设计） |
| **FAB 点击** | 展开半屏 Sheet：选择"添加好友"或"创建群组" |
| **添加好友** | 弹出输入框/扫码添加好友 |
| **创建群组** | 跳转创建群组流程（待设计） |
| **字母索引导航** | 点击/拖动字母 → 滚动到对应分组 |
| **长按 FriendItem/GroupItem** | 显示操作菜单（置顶/删除/举报等） |
| **Tab 切换** | 切换好友/群组列表，保持滚动位置 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **FriendsTab** | Normal | 默认灰色文字 |
| | Active | 主色文字 + 底部指示器 |
| | HasUnread | 显示红点 Badge |
| **GroupsTab** | Normal / Active | 同上 |
| **FriendRequestBanner** | Hidden | 无未读申请时不显示 |
| | Visible | 显示申请数和入口 |
| **FriendItem** | Normal | 默认显示 |
| | Online | 绿色状态点 |
| | Offline | 灰色状态点 |
| | Hover | 背景加深（桌面端） |
| **FAB** | Collapsed | 显示 ➕ 图标 |
| | Expanded | 展开为半屏 Sheet |
