#### 2.4 WebSocket 已读推送

客户端通过 WebSocket 发送 `mark_read`：

```json
// 客户端 → 服务端
{
    "type": "mark_read",
    "payload": {
        "chat_id": "xxx",
        "message_id": "xxx"
    }
}
```

服务端通过 WebSocket 广播给聊天室内所有其他成员：

```json
// 服务端 → 客户端（聊天室其他成员）
{
    "type": "message_read",
    "payload": {
        "chat_id": "xxx",
        "user_id": "xxx",
        "message_id": "xxx",
        "read_at": "2026-05-24T20:00:00Z"
    }
}
```

同时更新该用户的未读计数：

```json
// 服务端 → 客户端（发送者）
{
    "type": "read_receipt",
    "payload": {
        "chat_id": "xxx",
        "message_id": "xxx",
        "read_by": "xxx"
    }
}
```

#### 2.5 已读计数推送

当用户打开聊天室时，主动推送未读数：

```json
// 服务端 → 客户端
{
    "type": "unread_count",
    "payload": {
        "chat_id": "xxx",
        "unread": 5
    }
}
```

### 模块 3：富媒体消息（图片）

#### 3.1 数据模型

**MessageContent 扩展：**

```go
// internal/domain/model/message.go
type MessageContent struct {
    Type     ContentType  // text / image / file / voice
    Text     string       // 文本内容
    Url      string       // 图片/文件/语音的 URL
    MimeType string       // MIME 类型
    Size     int64        // 文件大小（字节）
    ThumbnailUrl string   // 缩略图 URL（图片用）
    Duration int          // 时长（语音/视频用，秒）
    Width    int          // 图片宽度
    Height   int          // 图片高度
}

const (
    ContentTypeText   = "text"
    ContentTypeImage = "image"
    ContentTypeFile  = "file"
    ContentTypeVoice = "voice"
)
```

#### 3.2 HTTP 文件上传（可选，当前阶段用 URL）

如果需要本地上传：

```
POST /api/v1/upload
Header: Authorization: Bearer ***
Content-Type: multipart/form-data
Body: file (binary)
Response: {
    "code": 0,
    "data": {
        "url": "https://cdn.aiim.com/uploads/xxx.jpg",
        "thumbnail_url": "https://cdn.aiim.com/uploads/xxx_thumb.jpg",
        "size": 123456,
        "mime_type": "image/jpeg"
    }
}
```

当前阶段直接用 URL：
```
图片消息直接发 URL，服务端不做存储
```

#### 3.3 发送图片消息（WebSocket）

```json
// 客户端 → 服务端
{
    "type": "send_message",
    "payload": {
        "chat_id": "xxx",
        "client_msg_id": "client-uuid-xxx",
        "content": {
            "type": "image",
            "url": "https://cdn.aiim.com/uploads/xxx.jpg",
            "thumbnail_url": "https://cdn.aiim.com/uploads/xxx_thumb.jpg",
            "mime_type": "image/jpeg",
            "size": 123456,
            "width": 1920,
            "height": 1080
        }
    }
}
```

#### 3.4 WebSocket 推送图片消息

```json
// 服务端 → 客户端（聊天室成员）
{
    "type": "message",
    "payload": {
        "id": "server-msg-id",
        "chat_id": "xxx",
        "sender_id": "xxx",
        "content": {
            "type": "image",
            "url": "https://cdn.aiim.com/uploads/xxx.jpg",
            "thumbnail_url": "...",
            "mime_type": "image/jpeg",
            "size": 123456,
            "width": 1920,
            "height": 1080
        },
        "status": "sent",
        "created_at": "2026-05-24T20:00:00Z"
    }
}
```
