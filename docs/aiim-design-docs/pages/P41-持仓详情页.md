# P41: 持仓详情页（金融研究切面）

> **版本:** v1.0 | **页面ID:** P41 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/stock/:symbol` |
| **目的** | 查看单个持仓的详细信息，包括行情、持仓数据、财务指标、相关新闻 |
| **前置条件** | 用户已登录，进入金融研究切面，从 P40 持仓列表点击进入 |

**嵌套关系说明：**
- `StockDetailPage` → 根页面容器

  - `PriceHeader` → 价格头部（LayoutComponent，核心信息区）
    - `CurrentPriceSection` → 当前价格区（FeatureComponent）
    - `ChangeSection` → 涨跌幅区（FeatureComponent）
    - `MarketDataGrid` → 行情数据网格（LayoutComponent）
    - `TrendChart` → 趋势图表（FeatureComponent）
  - `StockInfoCards` → 股票信息卡组（LayoutComponent）
    - `ValuationCard` → 估值指标卡（FeatureComponent）
    - `DividendCard` → 分红融资卡（FeatureComponent）
    - `ShareholderCard` → 股东信息卡（FeatureComponent）
  - `HoldingSection` → 我的持仓信息（LayoutComponent）
    - `HoldingCard` → 持仓数据卡片（FeatureComponent）
    - `HoldingChart` → 持仓盈亏图（FeatureComponent）
  - `RelatedNews` → 新闻区（LayoutComponent）
    - `NewsItem × N` → 新闻项（FeatureComponent）
  - `ActionBar` → 底部操作栏（LayoutComponent）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **切换K线周期** | 点击 分时/日K/周K/月K/年K → 刷新图表 |
| **触摸图表** | 显示十字光标 + 详情浮窗（日期/开盘/收盘/涨跌幅） |
| **收藏股票** | 点击 ⭐ → 添加到自选列表 |
| **点击新闻** | 新窗口打开新闻详情 |
| **编辑持仓** | 点击"编辑" → 跳转修改持仓页面 |
| **交易按钮** | 点击 → 跳转下单页面（待设计） |
| **添加价格提醒** | 点击"提醒" → 弹出设置价格提醒浮窗 |
| **查看十大股东** | 点击"查看 →" → 显示股东详情 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **ChangeSection** | Positive | 绿色文字 + ▲ |
| | Negative | 红色文字 + ▼ |
| | Neutral | 灰色文字 |
| **StarButton** | Starred | ⭐ 实心，黄色 |
| | Unstarred | ⭐ 空心，灰色 |

| | Neutral News | 显示灰色"中性"标签 |
