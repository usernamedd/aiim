# P10: 主聊列表页（主框架）

> **版本:** v1.0 | **页面ID:** P10 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/`（默认首页） |
| **目的** | 展示会话列表，是所有平台的入口主页，承载底部导航/侧边栏等主框架组件 |
| **前置条件** | 用户已登录 |

**嵌套关系说明：**
- `MainFrame` → 根页面容器（主框架，所有页面的父容器）
  - `TopBar` → 全功能顶部栏（C00）
    - `DomainSwitcher` → 行业切面切换器（FeatureComponent）
      - `DropdownMenu` → 下拉菜单（FeatureComponent）
    - `GlobalSearchButton` → 全局搜索按钮（UIComponent）
    - `NotificationBell` → 通知铃铛（FeatureComponent）
    - `ProfileAvatar` → 个人头像入口（UIComponent → C05）
  - `ContentArea` → 主内容区（LayoutComponent），Responsive 显示/隐藏
    - `Sidebar` → 侧边栏（C02，桌面端/平板端）
      - `SearchInput` → 会话搜索（FeatureComponent）
      - `ConversationSection` → 私聊分区（LayoutComponent）
        - `ConversationItem × N` → 私聊会话项（FeatureComponent）
      - `GroupsSection` → 群组分区分（LayoutComponent）
        - `GroupItem × N` → 群组项（FeatureComponent）
    - `ChatListArea` → 移动端聊天列表（LayoutComponent）
      - `ConversationItem × N` → 同上（复用）
      - `EmptyState` → 空状态占位（C11）
  - `BottomNav` → 底部导航（C01，移动端）
    - `Tab_Chat/Files/Debug/AI/Mine` → 各 Tab 项（FeatureComponent）

```
┌──────────────────────────────────────────────────────────┐

├────────────┬─────────────────────────────────────────────┤
│ [🔍 搜索]  │                                             │
│            │                                             │
```

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **ConversationItem 点击** | 跳转 `/chat/:userId`（P20 私聊页） |
| **GroupItem 点击** | 跳转 `/group/:groupId`（P21 群聊页） |
| **搜索按钮点击** | 跳转 P60 全局搜索页 |
| **通知铃铛点击** | 显示通知列表 Popover，或跳转通知页 |
| **头像点击** | 跳转 P50 个人设置页 |
| **DomainSwitcher 切换** | 切换行业切面，更新 UI 显示 → 刷新内容区 |
| **BottomNav Tab 点击** | 切换显示对应面板（聊天/文件/调试/AI/我的） |
| **侧边栏设置按钮点击** | 跳转 P50 个人设置页 |
| **下拉刷新（移动端）** | 刷新会话列表 |
| **会话列表滚动** | 隐藏/显示 BottomNav（视滚动方向） |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **ConversationItem** | Normal | 默认显示 |
| | Unread | 左上角显示未读数 Badge |
| | Active | 当前选中，高亮背景 |
| | Hover | 背景色加深（桌面端） |
| **DomainSwitcher** | Collapsed | 显示当前行业名称 |
| | Expanded | 下拉菜单展开 |
| **NotificationBell** | NoUnread | 灰色铃铛 |
| | HasUnread | 红色 Badge + 未读数 |
| **BottomNav Tab** | Normal | 灰色图标+文字 |
| | Active | 主色图标+文字 + 顶部指示器 |
