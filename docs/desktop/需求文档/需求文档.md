# 需求文档 - 桌面端

> 项目：AIIM - AI 即时通讯桌面客户端（Tauri）
> 版本：v1.0
> 状态：进行中

---

## L1 自然语言需求

我们需要一个运行在 Windows、macOS、Linux 三大桌面平台的即时通讯应用，支持私聊和群聊。用户可以像使用桌面版微信、TailGraham 那样，在电脑上高效地处理聊天消息。应用需要保证消息的即时送达，支持多窗口/多标签页聊天，内置深色模式，并且要节省系统资源（内存 < 150MB）。桌面端相比移动端可以显示更多信息（如消息列表支持更宽的宽度、支持键盘快捷键等）。

---

## L2 用户需求

| 角色 | 需求描述 |
|------|---------|
| 访客 | 启动 App 后快速登录，开始使用 |
| 普通用户 | 与好友私聊；在群聊中收发消息；多会话同时打开；修改个人资料 |
| 高效办公用户 | 键盘快捷键（Ctrl+Enter 发送、Ctrl+N 新建聊天等）；多窗口/标签页；置顶窗口 |
| 系统 | 开机自启动（可选）；最小化到系统托盘；系统通知；网络切换自动重连 |

### 4.2 技术实现要求

| 项目 | 要求 |
|------|------|
| 前端框架 | React 18 + TypeScript |
| 构建工具 | Vite |
| 状态管理 | Zustand |
| 样式 | CSS Modules 或 Tailwind CSS（待定） |
| Tauri 版本 | v2.x |
| 渲染引擎 | 系统 WebView（WebView2/WKWebView/WebKitGTK） |
| 本地数据库 | SQLite（Tauri 插件 @tauri-apps/plugin-sql） |
| WebSocket | 浏览器原生 WebSocket API |
| 图像缓存 | 浏览器原生或 React Query |
| 窗口管理 | Tauri 窗口 API（多窗口/标签页自实现） |
| 系统托盘 | @tauri-apps/plugin-tray |
| 自动启动 | @tauri-apps/plugin-autostart |
| 全局快捷键 | @tauri-apps/plugin-global-shortcut |

### 4.3 窗口管理策略

| 场景 | 实现 |
|------|------|
| 多会话标签 | 前端 React 状态管理，每个标签对应一个 chat_id |
| 窗口置顶 | Tauri `appWindow.setAlwaysOnTop(true)` |
| 自定义标题栏 | Windows/Linux 使用 Frameless Window + 自定义拖拽区，macOS 使用原生标题栏 |
| 系统托盘 | 关闭按钮触发 hide()，托盘菜单可 show() 或 quit() |

### 4.4 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Enter | 发送消息 |
| Shift + Enter | 换行 |
| Ctrl + N | 新建会话 |
| Ctrl + W | 关闭当前标签页 |
| Ctrl + Tab | 切换到下一个标签页 |
| Ctrl + Shift + M | 全局调出应用（系统级） |
| Esc | 关闭当前聊天框内容/取消操作 |

### 4.5 WebSocket 与本地数据库同步

| 事件 | 处理逻辑 |
|------|---------|
| 收到消息 | 保存本地 SQLite → 更新 Zustand Store → 渲染 UI → 发送 ACK |
| 收到 ACK | 更新消息状态 |
| 收到已读回执 | 更新消息状态 + 更新会话未读数 |
| 连接断开 | 指数退避重连（最大 30s），重连成功后同步离线期间消息 |
