## 核心变化：AI-Native

AIIM 的定位从「即时通讯工具 + AI 附加功能」升级为 **AI-Native Instant Messenger**，AI 是平台核心能力。

**新增核心模块：**
- 预置三大行业 Agent（软件工程 / 金融 / 医疗）
- AI 辅助消息编辑（润色 + 回复建议）
- 富文本消息格式 + 可视化编辑器
- Telegram Bot 式命令系统
- 消息队列与定时发送
- 用户自建 Agent（无代码 + 代码两种模式）

## 四层需求结构说明

| 层级 | 名称 | 描述 |
|------|------|------|
| **L1** | 自然语言需求 | 用自然语言描述业务场景和目标，不涉及技术细节 |
| **L2** | 用户需求 | 从用户（角色）视角描述需要什么，定义角色和场景 |
| **L3** | 功能需求 | 转化为具体的功能点（编号 F.x.x），每条功能有说明 |
| **L4** | 研发需求 | 细化为技术实现任务：接口设计、数据模型、WebSocket 协议、技术要求、里程碑 |
