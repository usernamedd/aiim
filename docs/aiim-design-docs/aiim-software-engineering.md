# AIIM 设计文档：软件工程场景
> 版本: v1.0 | 适用领域: 软件工程 | 创建日期: 2026-05-24

## 1. 设计目标与场景定位

### 1.1 产品定位

AIIM（AIIM）是新一代 AI 驱动的智能协作 IM 工具，**软件工程场景**面向开发团队，提供代码协作、调试、文件管理、Code Review 等开发工作流能力，与 AI 深度融合，实现"聊天即工作台"。

### 1.2 目标用户

| 用户角色 | 核心需求 |
|---------|---------|
| 开发工程师 | 代码查看、调试、文件协作 |
| Tech Lead | 代码审查、任务分发、进度追踪 |
| 测试工程师 | 调试日志分析、缺陷记录 |
| 全栈研究员 | 跨端协作 + 文档 + 代码一体化 |

### 1.3 核心能力矩阵

| 能力 | 金融研究场景 | 软件工程场景 |
|------|------------|-------------|
| 即时通讯 | ✅ | ✅ |
| 文件共享 | ✅ 图表/报告 | ✅ 源码/配置文件 |
| AI 分析 | ✅ 行研报告解读 | ✅ 代码解释/调试 |
| 消息引用 | ✅ 文献批注 | ✅ 代码提交引用 |
| 主动推送 | ✅ 持仓预警 | ✅ CI/CD 状态推送 |
| **专属 UI** | 仪表盘/研报面板 | **IDE 面板/调试视图** |

### 4.3 调试视图 (Debug View)

**功能描述：** 嵌入式调试控制台，支持断点设置、调用堆栈、变量监视、控制台输出。

**交互布局：**

```
┌───────────────────────────────────────────────────────────────────────┐
│ 🦊 调试控制台                                           [▶ 运行]     │
│                                                    [⏹ 停止]        │
├───────────────────────────────────────────────────────────────────────┤
│ 源文件: src/agents/executor.ts                                        │
│                                                                        │
│  1  │ import { Router } from './router';          │                     │
│  2  │ import { Planner } from './planner';        │                     │
│  3  │                                            │                     │
│  4  │ export class Executor {                     │  ← ← ← ← ← ← ← ← ←   │ ← 断点标记
│  5  │   private planner: Planner;                 │                     │
│  6  │                                            │                     │
│  7  │   async execute(task: Task) {───────────── ●│── 当前执行行 🔴      │
│  8  │     const plan = await this.planner.plan(); │                     │
│  9  │     console.log('[Executor] plan:', plan);  │                     │
│ 10  │     return this.run(plan);                 │                     │
│ 11  │   }                                         │                     │
│ 12  │                                            │                     │
│ 13  │   private async run(plan: Plan) {          │                     │
│ 14  │     for (const step of plan.steps) {       │                     │
│ 15  │       await this.dispatch(step);  ← ← ← ● │── 断点               │
│ 16  │     }                                      │                     │
│ 17  │   }                                        │                     │
│ 18  │ }                                          │                     │
│                                                                        │
├───────────────────────────────────────────────────────────────────────┤
│        调用堆栈              变量监视              控制台输出           │
│ ┌──────────────────┐ ┌───────────────┐ ┌──────────────────────────┐  │
│ │ ▶ executor.ts:7 │ │ task = {      │ │ > starting executor...    │  │
│ │   └─run()   L13  │ │   id: "t1",   │ │ > [Executor] plan: {...}  │  │
│ │     └─dispatch() │ │   type: "do", │ │ > dispatched step: 1/3    │  │
│ │                │ │ }             │ │ > done.                    │  │
│ │                │ │ plan = {...} │ │ > [WARN] slow query: 2.3s   │  │
│ │                │ │ result = null │ │                            │  │
│ └──────────────────┘ └───────────────┘ └──────────────────────────┘  │
└───────────────────────────────────────────────────────────────────────┘
```

**调试控制条（Debug Bar）：**

```
┌──────────────────────────────────────────────────────────────────┐
│ ▶ [Run]   ⏸ [Pause]   ⏹ [Stop]   ⟳ [Restart]   ➡ [Step Over]  │
│                                             ➜ [Step Into]      │
└──────────────────────────────────────────────────────────────────┘
```

| 按钮 | 快捷键 | 行为 |
|------|-------|------|
| ▶ Run | `F5` | 开始/继续执行 |
| ⏸ Pause | `F5` | 暂停在断点 |
| ⏹ Stop | `⇧F5` | 停止调试 |
| ⟳ Restart | `⇧⌘F5` | 重启调试会话 |
| ➡ Step Over | `F10` | 跳过当前行 |
| ➜ Step Into | `F11` | 进入函数内部 |
| ⏭ Step Out | `⇧F11` | 跳出当前函数 |

**调用堆栈（Call Stack）：**

```
调用堆栈
├── ▶ executor.execute()    L7   ← 当前帧
│     └─ Executor.run()     L13
│           └─ Executor.dispatch()  L15
│                 └─ PluginManager.invoke()  L42
└           └─ Router.resolve()    L8
```

| 元素 | 含义 |
|------|------|
| ▶ | 当前执行帧 |
| Ln | 代码行号 |
| 粗体 | 调用来源 |
| 单线缩进 | 调用链层级 |

**变量监视（Variables）：**

```
▼ 局部变量
    task  = { id: "t1", type: "do", status: "pending" }
    plan  = { steps: [ ... ], total: 3 }

▼ 闭包变量
    this.planner = Planner { ... }

▼ 监视表达式
    [+ 添加]
    task.status  = "pending"  🔵
    plan.total   = 3          🔵
```

| 颜色 | 含义 |
|------|------|
| 🔵 蓝色 | 基本类型 |
| 🟡 黄色 | 对象/数组 |
| 🟢 绿色 | 字符串 |
| 🔴 红色 | 异常/错误值 |

### 4.4 差异对比视图 (Diff View)

**功能描述：** 并排显示两个版本的文件差异，红色=删除，绿色=新增。

**交互布局：**

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ⟷ 差异对比                              [version_old.ts ▼] ↔ [version_new.ts ▼] │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  文件 A (旧版)          │        │  文件 B (新版)                         │
│  ───────────────────    │        │  ───────────────────                 │
│  1  const VERSION='1'; │        │  1  const VERSION='1';                 │
│  2  const x = 1;       │        │  2  const x = 2;  ✏️                   │
│  3  // old comment      │  ──►   │  3  // new comment    ✏️               │
│  4  function init() {  │        │  4  function init() {                   │
│  5    console.log(x);  │        │  5    console.log(x);                    │
│  6    fn();            │        │  6    await fn();      ✏️               │
│  7  }                  │        │  7    await init();   ✏️               │
│  8                       │        │  8                       │
│  9  export { init };   │        │  9  export { init, exec }; ✏️          │
│                                                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ 图例:  [🟥 删除]  [🟩 新增]  [✏️ 修改]      统计: +3 行  -1 行  变更 4 处      │
└─────────────────────────────────────────────────────────────────────────────┘
```

**差异类型视觉规范：**

| 类型 | 样式 | 说明 |
|------|------|------|
| 新增行 | 🟢 绿色背景 | 文件 B 中新增的内容 |
| 删除行 | 🟥 红色背景 | 文件 A 中删除的内容 |
| 修改行 | 🟡 黄色背景 + 左侧对比线 | 两处都有变化 |
| 移动行 | 🔵 蓝色背景 | 内容位置移动，功能未变 |
| 空行对齐 | ░░ 灰色占位 | 保持行号对齐用 |

**触发方式：**

```
1. /diff                        → 弹出文件选择器
2. 选中两个版本                 → 自动渲染并排对比
3. AI 自动分析差异              → 输出变更摘要
4. 支持逐行批注                 → 添加审查意见
```

**AI 差异分析输出示例：**

```

| UI 状态 | Zustand | 轻量状态管理 |
| 布局 | Tailwind CSS + CSS Grid | 响应式布局 |
| 代码高亮 | Prism.js / Shiki | 语法高亮库 |
| 文件树 | react-virtualized-tree | 大目录虚拟化渲染 |
| Diff 算法 | diff-match-patch | Google 开源 diff 算法 |
| 调试协议 | Chrome DevTools Protocol (CDP) | 浏览器调试能力 |
| AI 对话 | WebSocket + Server-Sent Events | 实时流式输出 |

## 9. 设计原则总结

| 原则 | 说明 |
|------|------|
| **聊天优先** | 所有功能融入消息流，不需要切换页面 |
| **AI 增强** | AI 理解代码上下文，不只是文档助手 |
| **场景隔离** | 金融/软件工程有独立 UI 模式和数据结构 |
| **可折叠** | 需要时展开 IDE，不需要时收起 |
| **实时协作** | 多人可以看到同一份代码、同一场调试 |
| **开发者友好** | 快捷键、低延迟、熟悉的工作流 |
