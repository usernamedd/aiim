# P20: 私聊页

> **版本:** v1.0 | **页面ID:** P20 | **适用端:** 全平台（Android / iOS / Windows / macOS / Linux）

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| **页面路径** | `/chat/:userId` |
| **目的** | 与单个用户的一对一实时聊天 |
| **前置条件** | 用户已登录，从 P10 会话列表点击进入 |

**嵌套关系说明：**
- `ChatPage` → 根页面容器
  - `TopBar` → 顶部栏（C00）
    - `UserInfo` → 用户信息区（FeatureComponent）
      - `StatusIndicator` → 在线状态指示器（UIComponent）
    - `MoreButton` → 更多操作菜单触发按钮（UIComponent）
  - `MessageList` → 消息列表容器（FeatureComponent）
    - `DateDivider` → 日期分割线（UIComponent）
    - `MessageBubble` → 消息气泡（FeatureComponent，核心组件）
      - 根据发送者身份区分左右布局（我：右侧，对方：左侧）
      - 包含多种消息类型子组件
    - `TypingIndicator` → 对方正在输入提示（UIComponent）
    - `ScrollToBottomButton` → 滚动到底部按钮（UIComponent）
  - `MultiPanel` → 多功能面板（C03）
    - `TabBar` → 面板内 Tab 切换
    - `PanelContent` → 面板内容区，条件渲染各 Tab 内容
  - `InputBar` → 底部输入栏（C04）
    - `AttachButton/FileButton/ScreenshotButton` → 各功能按钮（UIComponent）
    - `InputArea` → 输入区域（FeatureComponent）
    - `SendButton` → 发送按钮（UIComponent）
    - `AIAssistButton` → AI 辅助按钮（UIComponent）

## 5. 交互行为

| 行为 | 处理 |
|------|------|
| **发送消息** | 输入文字 → 点击发送/按 Enter → 显示 Loading → 追加到列表 → 清空输入框 |
| **图片发送** | 点击 📎 → 选择图片 → 显示缩略图 → 发送 |
| **文件发送** | 点击 📁 → 选择文件 → 显示文件名卡片 → 发送 |
| **截图发送** | 点击 📸 → 截图工具 → 发送截图 |
| **AI 辅助** | 点击 🤖 → 触发 AI 分析 → 在消息流中插入 AIBubble |
| **MultiPanel 展开** | 点击 Tab → 面板从右侧滑入，消息列表收窄 |
| **滚动行为** | 向上滚动隐藏 InputBar，向下滚动显示；滚动到底部隐藏 ScrollToBottom |
| **对方正在输入** | WebSocket 推送 typing 事件 → 显示 TypingIndicator |
| **消息已读** | 对方查看消息 → 我的消息 ✓✓ 变蓝 |
| **长按气泡** | 显示操作菜单（复制/撤回/删除） |
| **头像点击** | 查看对方个人资料卡片 |

## 6. 状态

| 组件 | 状态 | 表现 |
|------|------|------|
| **MessageBubble** | Sending | 灰色 ✓，有 Loading 动画 |
| | Sent | 灰色 ✓✓ |
| | Read | 蓝色 ✓✓ |
| | Failed | 红色 ⚠️ + 重发按钮 |
| **TypingIndicator** | Visible | 显示"对方正在输入..." |
| | Hidden | 不显示 |
| **MultiPanel** | Collapsed | 不显示，面板宽度 0 |
| | Expanded | 显示，面板宽度 320px |
| **ScrollToBottomButton** | Hidden | 已在底部，不显示 |
| | Visible | 有未读消息，显示按钮 + 红点 |
